# Security policy

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include the
affected version or commit, reproduction steps, impact, and any suggested
mitigation. Do not include production credentials, customer data, or details
from the private hosted service.

Only the latest release and the current `main` branch receive security fixes.
We will acknowledge a report as soon as practical and coordinate disclosure
after a fix is available.
